二叉树的性质

性质 1：(至多层节点数)
在二叉树的第i层上至多有2**(i-1)(i>=1)个节点

性质 2：(至多总结点数)
深度为k的二叉树至多有2**(k-1)(k>=1)个节点

性质 3：(总结点数)
对于一棵非空的二叉树T,如果其叶子节点数为n0(度为0),度为二的节点数为n2，则
n0=n2+1;
证明：
一棵二叉树的节点总数：
n = n0+n1+n2;
设B为分支总数，除根节点外其余节点都有一个分支进入则：
B = n1+2*n2;(度为2的节点有两个分支);
n =  B+1;
则：
n0+n1+n2 = n1+2*n2+1;
即：
n0(叶子)=n2+1;
>>>满二叉树：深度为K且含有2**(k-1)个节点的二叉树
>>>完全二叉树：深度为k、有n个节点的二叉树，当且仅当每一个节点都与深度为k的满二叉树中编号一一对应时。(前n-1层是满的底层允许在最右边缺少连续若干节点)
其特点：
1.叶子只可能在层次最大的两层上出现；
2.对于任一节点，若其右分支下的子孙最大层次为l,则其左分支下的子孙的最大层次必为l或l+1。
而偶数个节点的完全二叉树度为1的节点只会出现在最右侧，且只有左孩子、没有右孩子，不会存在只有右孩子的节点

性质 4：(深度)
具有n个节点的完全二叉树的深度为：log以2为底 n为对数向下取整 + 1；
证明：假设深度为k，则根据性质2和完全二叉树：
     2**(k-1)-1< n <= 2**k -1
即    2**(k-1)< n <2**k

取对数后  k-1 <...<k 

保留靠左、更小的整数再加1才是实际的层数所以向下取整
