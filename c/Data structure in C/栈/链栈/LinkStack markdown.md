    要malloc新建节点，否则直接让 p指向原有栈顶的节点时,意味着这是覆盖已有的数据，而不是插入数据。

    2. 放入元素

    3. 修改指针

把链表想象成一个只能从最前面进入的“单行道”：

1. 头结点 S：停在路口的交通警察，永远不动。
2. 第一辆到达的车（p1）：停在警察后面（S->next = p1）。
3. 第二辆到达的车（p2）：警察指挥 p2 停到 p1 前面（紧挨着警察），p1 被往后推了一位。
4. 第三辆到达的车（p3）：警察继续把 p3 停到最前面（紧挨着警察），p2、p1 依次往后挪。

最终：S → p3 → p2 → p1
