递归两大阶段总结（结合你的二叉树代码）
 
1. 递阶段（向下拆分，压栈）
 
1. 触发场景：函数里出现自身调用  Nodecount(子节点) 
2. 行为：暂停当前函数的计算，立刻进入子函数，不断往更小的子问题深入
3. 终止标志：触达基线条件  T == NULL ，不再继续往下调用
4. 特点：只拆分问题、不做求和运算，所有未完成的计算都会压入调用栈保存
 
2. 归阶段（向上回溯，计算汇总）
 
1. 触发场景：底层子函数碰到出口，返回一个确定数字（这里是0）
2. 行为：从最底层往回一层一层弹出栈里暂停的函数，把下层返回的数字代入上层表达式运算
3. 对应你的代码：每层执行  左结果 + 右结果 + 1 ，汇总当前子树总节点数，再把算好的数字返回给更上层
4. 特点：真正完成求和、合并结果，最终顶层函数返回完整答案
 
极简一句话区分
 
- 递：一路向下挖到底，只调用不计算；
- 归：从底往回算，层层合并返回值得到最终结果。
