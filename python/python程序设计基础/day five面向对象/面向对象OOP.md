Object-Oriented Programming
一、基础核心：类、对象、self、构造方法
1. 面向过程VS面向对象
·面向过程：数据、函数分开,代码零散

·面向对象：把属性(数据)+方法(操作)封装到类里，已对象为核心

·OOP四大核心特性：封装、继承、多态、抽象

2. 类与对象区分
·类Class：
事物模版/图纸,定义通用属性、方法;
class 类名: 定义,类名大驼峰
实例：
class Student: # 类
    pass
s1 = Student() # 对象/实例

3. 构造方法__init__(self)
·别称：构造函数，创建对象时自动调用,不用手动执行
·作用：给实例绑定属性,初始化数据
·规定：第一个参数必须是self,不能省略
·禁止：__init___只能返回None,别的不行
class Circle:
    def __init__(self, r):
        self.r = r # self.r 实例属性

4. self详解
·self代表当前正在创建/调用的实例对象本身
·所有实例方法第一个参数固定为self
·访问实例数据必须加self.属性名,不加就是局部变量

二、 两类属性：实例属性/类属性
1. 实例属性(对象独有)
定义在__init__内,格式self.xxx;
每个对象独立,互不干扰
2. 类属性(全类共享)
定义在类的内部、方法的外部;所有实例共用,修改类属性全部对象同步变化
class Student:
    school = "长沙工院" # 类属性
    def __init__(self,name):
        self.name = name # 实例属性
·访问： 类名.类属性 /  对象.类属性
·修改全局共享值：只能Student.school = xxx
